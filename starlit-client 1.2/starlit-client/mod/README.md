# Starlit (Fabric 1.21.11)

A visual-client style mod: Right Shift opens a menu with module cards.
Left-click toggles, right-click opens the settings (sliders, colours).
"Copy config" / "Paste config" share your setup as a text code.

Build:  gradle wrapper --gradle-version 8.14.3 && ./gradlew build
Jar:    build/libs/starlit-0.1.0.jar  (needs Fabric API 0.139.5+1.21.11)
Config: .minecraft/config/starlit.json
